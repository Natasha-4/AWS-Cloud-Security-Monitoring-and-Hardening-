# AWS-Cloud-Security-Monitoring-and-Hardening
Overview
This project shows how to create, secure, and monitor a virtual server using AWS.

Implementation Steps
1. Launched an EC2 instance
2. Restricted SSH access using Security Groups
3. Checked and secured SSH configuration
4. Set up CloudWatch monitoring
5. Created an alarm for high CPU usage (>80%)
6. Enabled email alerts using SNS
7. Services Used
8. Amazon EC2
9. Amazon CloudWatch
10. Amazon SNS

Result
The server was secured and successfully monitored.
An alert is sent when CPU usage goes above the set limit.
